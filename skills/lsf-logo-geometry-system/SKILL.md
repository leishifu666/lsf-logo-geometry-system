# LSF｜Logo 几何规整与标准制图

把主题、概念图或草图变成可复建、可编辑的标志。新设计可先生成探索板供选择，也可直接完成单个 Logo 与规范制图。**图片或草图要求“优化、制作、规整、标准制图”时，默认按几何规则重建**：保留识别特征和穿插关系，修正非预期歪线、半径差异与间隙不齐。不要把描摹像素误差当作完成规整，也不要把规整理解为删除全部小圆角。

## 按用户目标选择模式

- **探索板 → 用户选择 → 规整制图**：用户要“探索板、选择板、24 个方案、先给我挑”时，读 [探索板流程](references/exploration-board.md)。调用 Codex 内置 `image_gen`，使用 [内置完整提示词](references/exploration-board-prompt.md)，默认一张 4 列 × 6 行黑白探索板。展示后等待用户选定，再将选中方案重建为 SVG 和 B 式标准制图；不擅自代选，不先给 24 个方案全部制图。
- **描述 → 单个 Logo + 规范制图**：用户要“直接设计、直接出一个并制图”时，读 [直接设计](references/generation.md)。从描述或参考提炼概念，直接完成一款参数化标志、SVG 和 B 式同源制图，不插入探索板与选择门槛。没有待规整标志、也没要求先选方案的新设计请求默认走此入口；主题缺失且不能从上下文推断时才询问。
- **上传 Logo / 草图 → 几何规整**：已有标志要求优化成稿，读 [规整流程](references/regularization.md)。用户只说“保留原形”时保留轮廓意图与结构，结合上下文判断是否允许消除生成误差；“逐点不变、完全不改轮廓”则走保真模式。已是正式矢量、仅要求补制图的，不自行改造。
- **保真矢量化 / 反向测量**：明确要求保持原轮廓，读 [反向分析](references/reconstruction.md)。忠实保留光学校正或自由曲线，不能把圆角、非对称一律当成缺陷。
- 只问名称、评价或思路时只回答；不启动制作。书籍依据见 [阅读记录](references/book-methods.md)，不重复下载正文。

## 制作中的关键约束

新设计或用户要求「更简约、构造太多、减少圆和线」时，先按 [几何减法](references/geometric-economy.md) 压缩主轮廓、切口和独立构造规则，再细化圆角和制图。优先用少量必要原语及共享参数完成识别；不能用大量倒圆与精密标注补救复杂造型。已有正式图形仅补制图或保真矢量化时，不擅自删改轮廓。

新创作涉及两个以上主题、文字与图形结合，或用户反馈「拼得生硬、看不出某个元素」时，先读 [元素结合与语义检查](references/element-fusion.md)。先明确每个主题的可见识别特征和共享部位，再深化精确几何；不能用几何正确替代创意成立，也不能画完再给任意缺口、倾斜或圆角补寓意。抽象理念先选定具体含义及载体；名称未定时不能把理念自动当作正式品牌名。

1. 原图、图形组件与文字范围先分清；署名、网址、辅助线默认属于参考画面。保留源文件及来源信息，不把已有设计称为原创。
2. 区分**测得、拟合、本次设定**。低清图不能证明精确半径；辅助圆、网格、黄金比例必须有构造用途，不能装饰性补画。
3. 逐类检查外角、内角、折线转弯、弧线衔接和留白端部。需要圆润的节点构造成相切圆弧；遮挡交点或有意尖角可以保留。按部位设置少量半径，不强制全图同一个 R。
4. 成品、构造线和标注使用同一份参数。直边使用真实直线；圆弧使用圆弧原语。必要的自由曲线可以保留，不为“纯几何”损害识别特征。
5. 留白必须透明。优先用闭合轮廓与复合路径；必要的布尔差集/遮罩要验证反白和导出。不能用白色覆盖伪装孔洞。
6. 几何规整的验收重点是几何约束、识别关系与可用性。对原图差异用于解释改动，不以 IoU 越高越好；保真模式才按拟合误差评价。铅笔排线、候选线和辅助线不能直接作为真实实心轮廓计算“准确率”。

## 交付与验证

**默认采用 B 式「比例定位制图」**：按图形选择贯穿定位线、斜向平行线或放射线，显示有依据的构造圆，用灰色排线区分实体和留白，将 x 模数、间距、半径等尺寸直接标在对应位置。制作制图时读 [制图表达](references/construction-presentation.md)。A 式节点、控制柄、切向图用于按需补充局部细节，不作为默认主制图。

仅调整制图样式或用户圈出的局部时，锁定其余成品路径。参考线服务于形状，不能为了凑圆、网格或整数比例改动已确认的外形；做 A/B 对照时核对两版的成品路径、变换、位置与显示尺寸一致。

按任务生成：成品 SVG、PNG 预览、同源标准制图、原图/成稿对比、参数及简短验证说明。纯矢量成品不能嵌入原图；对比图可以。出现圆角反馈时增加局部放大，不能只给缩略图。输出先检查实际渲染，防止尺寸标注、文字和图形重叠。

探索板是概念位图，只在选定后进入上述精确交付；不将生成图片、图片中的网格或数值当作可编辑 SVG 或几何验证。直接设计模式一次交付单个成品与同源制图。

验证相切、角度/平行关系、间隙和圆角是否挤占短边；再检查透明反白、组件/孔洞/开放通道以及实际小尺寸。最小尺寸按本次测试给出，不能沿用别的 Logo 的数值。需要复建时交付参数与脚本，并从参数实际重建比较结果。**只把已经运行的检查写成通过**；几何浮点残差、源图差异和使用尺寸限制分开说明，未做印刷打样如实注明。

概念融合的新设计补充一张简洁的元素对应图或对应说明，指出两个识别特征及共享边界。分开报告「设计者语义自查」「已运行的几何/渲染检查」「外部人员识别反馈」；没有外部测试时不能声称一眼可辨或识别率通过。对应图用于解释与复查，成品仍须独立展示。

## 可用工具

操作说明和依赖见 [数据与工具契约](references/tool-contract.md)。脚本是辅助构造器，不是任意 Logo 自动识别器。

- `scripts/round_polygon.py`：Python 标准库；从顶点与逐点半径构造相切圆角，输出 SVG、圆角制图与参数。支持凹角和保留尖角，拒绝相邻圆角挤占短边。
- `scripts/build_sheet.py`：Python 标准库；从几何 JSON 生成主标志、反白与默认 B 式制图，支持同源定位线和图上尺寸；`sheet_style: path-detail` 可保留旧式细节页。复杂字标、局部放大或拥挤标注按制图表达规范编写项目脚本，不硬套通用布局。
- `scripts/measure.py`：Pillow + NumPy；已配准位图差异、拓扑与局部圆拟合。不是自动对齐器，也不能代替设计判断。
- `scripts/render_svg.cjs`：可选 Node.js + sharp 渲染；没有该工具可用环境已有的 SVG 渲染器，不能谎称已生成 PNG。
- `examples/rounded-corner.json` 与 `examples/tidebank.json`：合成用例，只用于检验工具，不是通用设计模板。

使用相对路径和环境已有依赖；不绑定个人用户名、固定工作目录、Windows 字体或特定图像工具。只有缺少会改变结果的关键信息时才提问，继续能独立完成的工作。
