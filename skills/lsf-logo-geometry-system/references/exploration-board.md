# 探索板 → 用户选择 → 规范制图

此入口面向先探索再选择的请求。探索阶段产物是一张概念位图；选定后才生成规范矢量，不把“能生成一张图”描述为“已经完成标准制图”。

## 生成前

从已有描述、参考和上下文确定主题、品牌名（如有）、气质、用途、必须保留/避开的元素。主题已明确就制作，不追加完整品牌问卷；没有主题且无法推断时，简短询问主题，这是生成依赖。

提炼可转译的视觉核心，例如动作、结构、空间关系、情绪和隐喻。发散不同概念，不把 24 个方案做成同一符号的微小变体。不是必须覆盖模板列举的全部设计方法；按主题选择。

简约方向补入 [几何减法](geometric-economy.md) 的要求：少量必要原语、少转折与切口、可复用的曲率和方向；优先让一个形体承担多个含义。生成图上的构造圆数量不算验证，不能为宣称「最少」而删掉关键识别特征。

多主题融合先读 [元素结合与语义检查](element-fusion.md)。在完整模板后补入主题的关键识别特征、几种适配的共享关系与需避开的误读；不要把两个词直接交给模型后用事后寓意解释结果。让方案在结合操作上分化，例如共边、正负形、局部置换、字图同构，而非统一贴上第二个图标。保留用户原始模板正文，不用方法摘要替换它。

读取 [完整提示词模板](exploration-board-prompt.md)，把所有 `【主题】` 替换为当前主题，保留其 4 列 × 6 行、24 个方案、黑白极简和无底部编号的要求。模板正文不缩写为摘要。将当前用户明确给出的约束补充到提示词中并优先执行：已有品牌名不得自动改名；用户要求无文字时不强加字标；指定方案数量、语言或配色时覆盖模板默认值。只有未指定名称时才使用模板的英文自动命名。

## 用 Codex 内置生图

- 使用环境提供的内置 `image_gen` 图像生成工具；工具名和参数以当前工具说明为准。本会话形态可能是 `image_gen__imagegen`。不要通过外部网站、第三方插件、自己写 API 调用或 SVG 拼图替代用户要求的内置生图。
- 一张探索板是一个图片产物，默认用一次生成调用产生完整 24 格板；不是必须生成 24 张独立图片再拼接。生成新板不传不存在的参考图片。使用参考图片时明确其用途，并遵守当前工具对本地路径和会话图片的引用约定。
- 若环境有 `imagegen` 技能，按其内置工具工作流执行。不要向用户索要 API key，也不要静默改用 CLI/API。内置工具不可用或失败时如实说明；外部替代需要用户另行指定。
- 保存实际使用的提示词和返回的探索板文件，用原生图片展示结果。需要归档时复制工具返回的实际文件到当前任务交付目录，保留各版，不能编造输出路径。
- 检查实际图片的方案数、行列、重复程度、留白、文字可读性和黑白约束。发现缺格、乱码或明显重复时，做一次针对性修正并复查；仍不满足时说明具体问题，不谎称已经完整通过，也不无止境重试。只在真正调用工具后声称生图完成。
- 融合探索还要指出哪些格确实保留双方特征、哪些只有一方或只是并列；不要将全部 24 格宣称为成功融合。不因此替用户选择或提前规整未选方案。

## 展示并等待选择

展示探索板，让用户用“第几行、第几列”或图形描述选择；从上到下为 1–6 行，从左到右为 1–4 列，不在原板底部另加编号。多版并存时同时记住板的文件/版本与位置。

这一处等待来自用户选择式工作流的要求。没有选定前不擅自挑一个进入制图，也不把推荐当作选择；可以推荐但要等用户决定。用户说“你来选”“直接用第 3 行第 2 列”或已明确选中时，授权已具备，不重复确认。

用户只调整主题或要求再来一板时，生成新版并保留旧版；用户明确选择多个时只处理所选项，不自动合并它们。

## 选定后

1. 核对板版本和行列对应的具体方案；先看实际图形，再锁定图形、负形、字标和组合关系。描述仍可能指向多格时，仅询问这一歧义。
2. 若当前清晰度足以判断结构，直接按 [规整流程](regularization.md) 重建。小图细节模糊时可用内置生图进行选中方案的单独细化，但明确锁定轮廓意图，不让细化生成另一个概念；不得把重新生成当成原方案的精确放大。
3. 确定真实直线、圆弧和必要的自由曲线，校正非预期抖动、圆角和间隙；探索图上的文字在矢量稿中校对。保留用户选中的识别特征，不为凑网格而换形。
4. 输出可编辑纯矢量 SVG、透明 PNG、[B 式同源标准制图](construction-presentation.md)、选中方案与成品对照、参数和验证说明。生成图片上的圆、网格或数字不是精确几何证据。

## 路由核对例

| 请求 | 应有行为 |
|---|---|
| “给山地骑行品牌做 24 个 Logo，我来挑。” | 使用完整主题模板调用内置生图，展示一张板并等待选择。 |
| “用刚才那张第 2 行第 3 列。” | 检查选中格，直接规整并输出 SVG 与 B 式制图。 |
| “你替我从这张里选一个并制图。” | 可自行选择，说明理由后完成制图，不再设选择门槛。 |
| “直接设计一个山地骑行 Logo 并制图。” | 走直接设计模式，不生成探索板。 |
| “更新 skill，加入探索板模式。” | 更新技能文件；没有实际设计主题时不额外生图。 |
