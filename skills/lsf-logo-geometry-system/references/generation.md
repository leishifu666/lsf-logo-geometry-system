# 描述 → 单个 Logo + B 式规范制图

用户要求直接设计并制图时，依据主题描述、参考或已有 brief 完成一个主方案及规范交付，不先生成 24 格板，不新增“先选方案”步骤。仅主题缺失且上下文无法推断时询问；名称、气质等非关键空缺可说明假设后制作。用户要先看多个方向时改走 [探索板流程](exploration-board.md)。

确定名称、行业、核心含义、主要尺寸和禁用元素；已有 brief 不重复提问。一次选择一个可表达的视觉主题，不默认把所有新品牌做成放射花瓣，也不套用上一个标志的角度、形状或半径。

涉及元素结合时读 [元素结合与语义检查](element-fusion.md)。用一段内部设计记录明确：A 的识别特征、B 的识别特征、优先读法、共享部位、所用操作和主要误读。抽象理念需先具体化，行业不自动决定全部风格。用少量结构草图检查共享关系；用户未要求探索板时，自行比较并完成一个主方案，不新增确认门槛。被否定的方案需改变造成失败的结合关系，不能只换圆角或增加解释。

创作路线按输出需要选择：能由几何关系直接表达时，在矢量参数中设计；用户明确要求使用生图，或需要位图概念探索时，使用 Codex 内置 `image_gen` 生成单个方案，再转入精确构造。此模式不必调用 24 格提示词；若需要生图，提示词明确“单个 Logo”，保留当前名称与约束。最终不能只交付一张带辅助线的生成图片。

1. 把主题转成可检查的图形关系。既列出支持该含义的可见线索，也列出其他可能读法；汇聚、循环、协作等解释本身不是识别证据。对元素结合候选做双读、共享必要性与删减检查，选择保留双方特征且结构较少的一种，简述选择后制作。设计者自查不冒充外部盲测。
2. 按 [几何减法](geometric-economy.md) 先压缩主轮廓：删去非必要部件、转折和细槽，合并能共用的形体，比较无辅助线的黑色实心缩略图。保留双方识别特征后，才定义模块 x、坐标系与少量必要原语，细化圆角。整数倍只是便利工具，不必所有尺寸都整齐，也不能为减少计数把折线改成复杂曲线。
3. 写参数及构造序列，明确旋转中心和顺序。圆弧写中心、半径、起终角与方向；胶囊区分全长、直线段长和端圆半径；旋转后的包围盒重新计算，不能把外接圆直径当实际宽度。
4. 从同一份几何生成实心主标志和 [B 式比例定位制图](construction-presentation.md)，将定位线、有效构造圆、灰色排线和图上标注关联到真实参数。最终精确制图以可编辑矢量和可复建参数为准，不得把生图模型画出的数值当作测量值。
5. 圆切线检查半径向量与切线垂直；相邻弧检查端点和切向一致。布尔后确认组件和孔洞；将负形放在有色底上确认透明正确。
6. 渲染黑白/反白以及 16、24、32、48 px 或实际使用尺寸，检查细线消失、粘连、小孔和方向辨识。记录结果；最小尺寸是场景建议。没有实体打样不报告印刷通过。
7. 一次交付单个主标志 SVG、透明 PNG、B 式制图、参数及验证说明；融合任务附元素对应与主要误读，纯净成品单独展示。若经过生图探索，保留实际提示词与选用概念图，说明几何规整改动；直接在矢量中设计则不虚构“原图”对比。原创试作不等于做过商标检索；用户没要求检索时不声称名称或图形具有法律唯一性。

## 可复建说明的粒度

另一位设计师只读参数即可得到一致轮廓。应包含原点、轴向、每个原语的尺寸/位置、复制变换、切除顺序和残差路径；“画一个圆然后适当调整”不够。

## 建议版规范

用品牌应用来选择安全区，例如较窄的数字导航空间与大幅海报可能需要不同组合。标注建议值及依据，不默认写 `2x`。最小尺寸给出实际测试通过的范围和测试限制，不自动写“印刷 8 mm”。只有已做的检查列为通过。
