## 有限的方法提炼

书中的构造展示了由基础形状推导比例、用调节线观察布局，以及用重复模块比较尺寸。两个案例把模块、方向和圆径联系到实际作品。技能借用这些分析思路，要求每项几何说明落实到可定位的形状。

## 本技能独立增加的工程规则

下面是本次实现的设计选择，不归为书中算法：

- 将分析关系分为测得、拟合、建议；不从几何巧合断言历史意图。
- 保真模式使用误差约束比较候选；几何规整模式保留识别结构并修正不规则边线，报告主动改变。两种模式都限制不必要参数，允许保留必要的自由曲线。
- 用一份 JSON 同源生成主标志、辅助线与标注。
- 使用像素轮廓距离、面积重合及组件/孔洞变化检验重建。
- 用反白、小尺寸和透明度检查决定使用建议。

不把书中关于黄金比例审美偏好的表述当作普适的科学结论或所有 Logo 的设计要求。
