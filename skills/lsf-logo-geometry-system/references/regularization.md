# 图片与草图的几何规整

## 从参考中保留什么

先识别外轮廓意图、部件数量、穿插顺序、留白连通关系与文字。保留这些识别特征，修正图片生成或手绘造成的边线波动。没有充分证据时，不把非对称、不同条宽或光学校正判为缺陷。完成当前交付，不把“可以继续做 SVG”留作未完成的选项。

制作前用一句话说明采用规整模式和主要假设即可；用户已经要求优化，不需再次批准可逆的几何调整。只是分析或保真请求不得转成重设计。

## 建立少量可解释的规则

1. 先固定整体尺度与坐标，不非等比拉伸。识别长直边方向、平行边组、重复部件和对称关系；角度来自当前造型，不固定用 60° 或 51°。
2. 以法线距离衡量斜向宽度与间隙，不能用水平距离冒充垂直宽度。需要等宽时由共同方向和偏移量直接生成两条边。
3. 建立圆角清单：外轮廓凸角、内侧凹角、折线转折、圆弧接缝、留白端部。标记“圆角 / 保留尖角 / 遮挡交点 / 无法判断”。先检查实际图像，再按结构设半径。
4. 直线交点倒圆使用切点与圆心计算；半圆收口半径为通道宽度的一半。外侧与内侧半径不一定相同，所有圆角也不应全设同一半径。明确精确相切的节点，保留的交点不用假称相切。
5. 验证相邻圆角的切退距离之和小于共用边长，检查圆弧扫向、短边消失、负形闭塞和自交。局部圆角校验不等于全轮廓自交证明。
6. 正式文字优先用有依据的字形或授权字体；需要规整重复字母时使用同一个母版。不要随意替换字体后声称完全保留原标志。

## 特别注意圆角反馈

用户说“少了圆角”时，对照原图的局部折角，不只检查外圈的大圆弧。放大展示原图、旧版和修正版的同一位置。用真实路径更新圆角，不能靠模糊、抗锯齿或 `stroke-linejoin` 装饰来掩盖实心路径中的尖角。低清原图只能支持外观判断，精确半径写为本次设定。

## 同源制图与验证

- 主制图默认使用 [B 式比例定位表达](construction-presentation.md)，从图形选择贯穿参考线和图上尺寸。路径控制柄只用于按需细节图；不能因更换制图样式而改变已确认的轮廓。
- 主 SVG 使用已构建轮廓；辅助圆直接取圆心、半径与切点。尺寸文字引用参数，调整参数后重新生成两者。
- 复杂图形可写项目构造脚本；附带的通用脚本并不覆盖所有交织与弧弧过渡，不应硬套。
- 圆角残差、相切点积属于构造检查；像素差异属于源图对照；小尺寸连通属于使用检查，三者不能互相替代。
- 区分封闭孔与向外开放的狭槽。细通道在小图里可能变成多个小孔，组件数不变仍是失败；检查负形拓扑及关键留白与背景的连通性。
- 选择与应用相符的几组像素尺寸，记录栅格化和阈值。最小尺寸建议需要显示余量；小图拓扑通过不等于所有圆角可辨。
- 透明和反白放在有色底上查看；主 SVG 不嵌位图。文字标签可用环境字体回退，最终字号/排版须目视检查；缺中文字体时安装合适字体或改用可用标签，不能交付乱码预览。

## 草图输入的报告

铅笔排线、擦改和网格使源图不存在唯一可靠的实心 mask。此时交付同尺度视觉对照、明确构造参数与几何验证，不编造 IoU 或“99% 精度”。若手动选定干净轮廓作测量参考，记录选定范围和不确定性。

保留完整参考和署名；对比图可裁中央图形并注明，成品按用户目标只制作标志。没有品牌检索任务时，不宣称法律唯一性或官方规范。

## 完成标准

成品可编辑、圆角和间隙有依据、辅助线与成品一致；渲染不重叠不裁切；已检查关键拓扑和小尺寸。交付参数复建脚本时从参数重新运行，不仅比较缓存 path；旧版本另存，原图不覆盖。
