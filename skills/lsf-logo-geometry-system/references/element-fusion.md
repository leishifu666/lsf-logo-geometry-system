# 元素结合：从含义到共享结构

用于新设计中的多主题、字图融合，以及「生硬、看不出另一元素」的修订。只做既有 Logo 规整、尺寸制图时，不重新发明寓意或改造用户已确认形状。以下方法是操作归纳，有交叉，不是穷尽分类。

## 先明确要表达什么

把每个主题写成具体识别线索：物体的诊断性轮廓、字的关键笔画，或关系中的动作。抽象理念先确定一个含义与视觉载体。例如「自我认知」「独特身份」「自我接纳」是不同方向；人形仅表示人，倾斜也不自动表示个性。不能在画完后切换含义为结果辩护。

保留正式名称、品牌理念、行业三者的区别。语义字可以用于字图同构，但应说明它是概念线索，不据此擅自命名品牌。行业识别不要求每个品牌都画行业物件；只有用户需要两个元素都可见时，才把双读作为当前任务的约束。

用简短设计记录明确：

- **A / B 的识别特征**：各自至少指出一个具体部位，而不是形容词。
- **主次**：先读哪一个，另一个怎样被发现；不是强制同等面积。
- **共享关系**：哪一条边、块面、笔画或动作同时承担两种含义。
- **方法与误读**：使用什么操作，最可能被看成什么别的东西。

名称或主题能从上下文确定时继续制作。非关键空缺可以说明假设，不变成固定品牌问卷。

## 按形态匹配选择操作

| 方法 | 操作 | 主要失败信号 |
|---|---|---|
| 共线 / 共边 | 让兼容轮廓共享一段边界 | 为迁就其中一方把另一方拉歪 |
| 整体同形 / 双读 | 同一个整体形体支持两种读法 | 两者都只剩模糊近似 |
| 正负形 | 实体承载 A，真实透明留白承载 B | 缝隙本身不像 B；反白或缩小后消失 |
| 局部置换 | 用 B 替换 A 的一个结构部位 | B 像贴纸；A 丢失关键特征 |
| 特征嫁接 | 把 B 的少量诊断性特征接入 A | 任意主体都能加同一装饰 |
| 字图同构 | 笔画、单字或词组同时形成物形 | 字或物只有一方能读 |
| 共笔 / 连字 | 两个已确定字符共享笔画 | 无依据造缩写；重叠成线团 |
| 叠合 / 交集 | 用重叠部分表达共同点或形成新形 | 只增加视觉噪声，没有有效关系 |
| 穿插 / 互锁 | 用穿过、扣合、编织组织形体 | 遮挡错误；交点过多 |
| 包裹 / 嵌套 | 用包含关系表达归属、保护等 | 仅仅一个小图标放进大图标 |
| 聚合 / 拼形 | 小元素组成另一种大轮廓 | 只在很大尺寸能看清 |
| 模块 / 重复 | 同一原语通过排列、旋转形成系统 | 只有秩序，缺乏主题特征 |
| 省略 / 闭合 | 删除部分轮廓，保留补全线索 | 缺口破坏识别，靠解释补全 |
| 旋转 / 镜像 / 异读 | 转向或对称关系产生第二读法 | 必须告知特定角度才勉强成立 |
| 连续形变 | A 的结构连续转为 B | 中间形混乱；静态截帧无意义 |
| 动作 / 关系 | 用拥抱、展开、贴合等组织双方 | 退化成复杂叙事插画 |

并置也是有效排版方式；若目标是一个共享结构的符号，不能把并置当作融合完成。选择适配的方法即可，不要求每次遍历 16 类或输出固定数量草案。

## 先检查语义，再完成几何

用少量低成本结构草图比较候选。检查：

1. **双读**：分别指出 A、B 的轮廓证据。没有证据就调整结构，不用标题或故事替代。
2. **共享必要性**：两者具体共用什么？删掉第二个线索后形体会怎样变化？可随处粘贴的装饰通常没有建立结构关系。
3. **减法**：删去非识别细节后，两种读法是否仍有依据？过度删减也会破坏识别。
4. **图底与尺度**：实际查看实心、反白、小尺寸；细小负形无法承担关键语义。
5. **误读**：记录主要竞争读法。不要在看到结果后重新定义原始 brief。

几何草图可贯穿构思，但精确制图不能替未成立的含义背书。选定结构后用共享模块、真实直线、圆弧、切线、布尔运算和必要曲线复建；不要事后叠无用圆。字母和有机轮廓也不能为凑圆而变形。

圆润 / 硬朗由气质、结构、尺度共同决定，不按行业一刀切。保留对识别有用的尖角；接触、转折或细小生产边缘可适当圆化。用有限半径族控制一致性，避免「所有点都倒圆」与「所有曲线都拉直」两个极端。

## 如何报告结果

分开写三类证据：

- 设计者自查：指认双方线索、共享部位和未消除的误读。
- 机器验证：实际运行过的几何约束、拓扑、反白、小尺寸与同源路径检查。
- 外部识别：只有真实获得他人反馈时才记录；未做就注明未做，不编造盲测或识别率。

无需额外设批准步骤。用户要求直接成稿时完成一款主方案；要求探索板时沿用用户选择流程。已选结构的改动范围以用户授权为准。

## 方法依据与实际阅读范围

这些是对视觉融合研究的 Logo 工作流适配；论文没有提出上面完整的 16 类，也未证明任一新方案必定有效。无需每次重复联网，需扩展或核实时再查原文。

- [VisiBlends，CHI 2019](https://www.cs.columbia.edu/~chilton/web/my_publications/VisiBlends_CHI2019.pdf)：实际阅读第 3–5 节（PDF 第 3–6 页），关于双概念可辨认、形状匹配与流程。应用于 Logo 是本技能的转译。
- [TypeDance，2024 公开论文](https://arxiv.org/html/2401.11094v1)：实际阅读第 3.1、3.3 节，笔画 / 字母 / 多字层级与映射。没有运行论文系统。
- [Less Is More，2026 预印本](https://arxiv.org/html/2609.00476v1)：实际阅读第 3 节及第 4 节部分，主次、共享轮廓、正负形区域选择；不是通用穷尽分类。
- 可复查案例：[手与鸟 / Human Rights Logo](https://www.humanrightslogo.net/sites/default/files/InfoSheet_EN%20aktuell.pdf)、[FedEx 字间负形箭头](https://newsroom.fedex.com/newsroom/middle-east-indian-subcontinent-and-africa/fedex-express-celebrates-uae-superbrand-award-for-fifth-consecutive-year)、[Mother & Child 档案](https://lubalin100.com/day-56/)。复用操作原理，不复刻成品轮廓。
