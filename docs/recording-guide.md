# Codex Skill 录屏演示清单

这份清单用于录制一条安装与功能演示视频。

## 先备好这些窗口和文件

1. 浏览器打开 [GitHub 仓库](https://github.com/leishifu666/lsf-logo-geometry-system)，停在README安装位置。
2. Codex打开一个用于演示的任务，收起无关侧栏；确认能写入输出文件。
3. 预先打开下面的案例文件，方便录到对应步骤时切换。
4. 录屏和讲解素材分别准备；生成等待不要边等边讲。
5. 准备一个自己的演示网页，显示实际导航栏；没有线上产品就标“应用示意”。选用KUNKUN图形展示SVG缩放、主题换色，鸟形案例用来说明复杂图形的小尺寸限制。

## 录屏实际顺序

**A. 效果素材，先录20–30秒。**
先录对照图全貌，再录标准制图，最后录眼部、两处圆角和下方圆弧。鼠标落到位置后停2秒，方便剪辑。不要用缩略图糊着展示。

KUNKUN可在开头作为2–3秒的案例快切，用总览图接B式制图；仍然只制作一条视频。鸟形的圆角、眼部解说对应鸟形画面，不套到KUNKUN上。

**B. 安装素材，录完整操作。**
在README选中安装指令 → 复制 → Codex粘贴 → 发送 → 真实结果。你本机已安装同名Skill，可以展示安装指令和已安装提示，不用为录制删除已有定制。若要演示首次安装，需要在自己准备的未安装配置中录，不把临时下载目录冒充日常安装目录。

**C. 上传与运行，等待段保持录制。**
上传鸟形输入图，发送下方制图指令。输出到独立演示目录；等待期间保持原始录屏，剪辑时压缩或跳过。实际结果若与历史案例不完全相同，分别标明。

**D. 输出检查，录30–45秒素材。**
依次打开SVG、透明PNG、制图和对照；展示文件名及实际内容。SVG可在浏览器放大，若有矢量编辑器，再录节点或路径选中的画面。放大位图不等于证明它可编辑。

**D2. SVG与PNG对照，另录约60秒素材。**
从同一个KUNKUN纯矢量图形导出64px宽的透明PNG，和原SVG放在同一个网页，两者显示宽度都从64 CSS px调到256 CSS px。标明PNG原始宽度、显示宽度与设备像素比；不要人为给PNG加模糊或强制像素化。再补一张足够分辨率的PNG以同样尺寸显示，说明位图并非天然模糊，高像素密度屏幕也需要相应像素数。

主题演示将SVG内联到网页，给实际路径使用`fill="currentColor"`并修改容器颜色；切浅色和深色背景。不要用普通`img`引用后假装页面CSS能直接改内部路径，也不把透明背景说成SVG独有。若要讲文件体积，在相同图形和输出条件下实际测量；不预设SVG一定更小。以上是待录制步骤，不代表已有网页成片或已测过体积。

**E. 探索模式，录15–20秒素材。**
展示探索指令和完整板，再局部放大几格。直接使用图库时字幕写“历史探索板”；现场生成则保留真实返回画面。DRIP与这张24款板不是一段已验证的连续选择记录，不剪成“我点这格就得到了DRIP”。

**F. 结尾，录仓库首页5秒。**
显示仓库名、安装说明和案例入口。最后停稳，给观众截图时间。

## 三段可粘贴的文字

### 安装

```text
$skill-installer install https://github.com/leishifu666/lsf-logo-geometry-system/tree/main/skills/lsf-logo-geometry-system
```

### 上传后制图

```text
$lsf-logo-geometry-system
把我上传的这个Logo做成规范制图。
保留鸟形、眼部负形及各块面的关系，修正不规则边线与圆角。
能用真实圆弧构造的部位采用圆弧，必要的自由曲线保留，不添加装饰性构造圆。
输出可编辑SVG、透明PNG、B式标准制图、原图对照和小尺寸检查说明。
新建一个演示输出目录，保留原始文件。
```

### 探索板

```text
$lsf-logo-geometry-system
为猫咪与咖啡自然融合的品牌，生成一张4列×6行、24款黑白极简Logo探索板。
让元素共用轮廓或负形，不要简单把猫塞进杯子。
先让我选方案，暂不规整或制图。
```

## 一套素材适配三个平台

成片建议1080×1920、30fps；这是统一制作方案。录屏可以保留横向原始画面，但在剪辑里放大到关键窗口或输入区，不把整张桌面缩进手机画面。口播字幕每次1–2行，关键尺寸/指令与字幕不要重叠。生成等待标“等待已剪辑”，不要标未经计时的“30秒生成”。

视频面向用AI做个人小产品、网页和原型的人。展示实际文件、网页效果和使用边界；无需为三个平台分别录制。
