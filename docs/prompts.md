# 可复制的使用指令

## 先探索再选择

```text
$lsf-logo-geometry-system
为猫咪和咖啡自然融合的品牌生成24款极简黑白Logo探索板，4列×6行。
不要把完整猫图标直接塞进杯子。先让我选，暂不做标准制图。
```

## 选定后制图

```text
$lsf-logo-geometry-system
用我上传的这款，保留识别特征、尖角和负形关系。
修正不规则边线与圆角，输出纯矢量SVG、透明PNG、B式标准制图、原图对照和检查说明。
圆与线必须有真实构造依据；必要的自由曲线保留，不强行套圆。
```

## 直接设计

```text
$lsf-logo-geometry-system
直接为一个山地骑行社群设计一款简洁黑白图形，结合山峰与车轮。
不先出探索板，完成可编辑SVG和B式标准制图，说明使用的几何规则与限制。
```

## 保真和优化分别表达

完全不能改外形时：`按保真模式矢量化，不主动改变轮廓，报告拟合误差。`

可以规整时：`保留识别特征，允许纠正歪线、曲率和圆角，不要求逐像素一致。`

只换制图表现时：`锁定成品路径，只调整参考线、排线和尺寸标注。`
